### Scoring rule

- Counted per Note: image links in `note.md` (where-this-fits map excluded), GIFs, numbered `##` sections (Summary, Prerequisites, Sources, Key terms excluded) and prose words outside code and display maths.
- **strong:** <=400 words per visual and >=60% of sections illustrated. **adequate:** <=600 words per visual and >=50% illustrated. **weak:** worse than adequate. **text-heavy:** >900 words per visual or <30% illustrated.
- A Note whose core idea is a process with no animation is capped at **weak**; one whose GIF misses the core process is capped at **adequate**.
- Process / animated / proposals are hand judgements from each Note's key points, section titles and figure names.
