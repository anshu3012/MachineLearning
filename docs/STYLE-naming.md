# Naming rule for Notes (from the user)

- **No vague pronouns.** Do not start a sentence with "It", "This" or "That" pointing back at an idea. Name the thing instead: "This penalty shrinks the weights", not "This shrinks the weights".
- **Use professional standard terms, and define each one in plain words the first time it appears in a Note:**
  - **feature**: an input variable (one column of the data table);
  - **target**: the output we predict;
  - **observation**: one record (one row of the table).

  Use "column" and "row" only when the text is about the table or DataFrame itself, for example a pandas operation.
- **Simple, but precise.** Precise names do not mean jargon. Every term is defined before it is used.
